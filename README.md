# 🍽️ ValtellinaAdvisor

**Discover, review and share your experience with restaurants in Valtellina.**

Valtellina Reviews is an Android application developed as a **school project**.

The application allows users to discover restaurants in Valtellina, read reviews and share their own experiences.

## 🎓 School Project

The main goal of this project was not only to develop an Android application, but to **bring together different areas of knowledge acquired throughout the Informatics course**.

The project combines:

* ☕ **Java & Android** — development of the mobile application and its user interface
* 🗄️ **Databases** — design and management of the data used by the application
* 🌐 **PHP** — development of the server-side logic and communication between the app and the database

Working on the project made it possible to understand how these technologies can work together to create a **complete client-server application**.

## 💡 What I learned

Through this project, I gained practical experience in:

* Developing Android applications with Java
* Designing and interacting with relational databases
* Creating PHP backend services
* Connecting an Android application to a remote database through a backend
* Managing data exchange between different parts of an application
* Structuring a complete software project from the mobile client to the database
